# Définitions de trackers

Définitions au format Cardigann issues du projet [Prowlarr/Indexers](https://github.com/Prowlarr/Indexers)
(GPL-3.0), interprétées directement par Noosfin (`src/scraper/cardigann.rs`) : aucun Prowlarr ni Jackett n'est
nécessaire. Seuls les trackers publics vidéo sont embarqués.
